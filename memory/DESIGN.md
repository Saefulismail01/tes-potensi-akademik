# Design: PAPS — Platform Akademik Penalaran Sinonim

Generated by office-hours on 2026-05-13
Status: DRAFT
Mode: Builder

## Problem Statement
Membuat platform quiz personal untuk persiapan Tes Potensi Akademik (TPA) S2, fokus pada Penalaran Verbal — dimulai dari Sinonim. Ingin seperti Quizlet tapi versi自制 (self-built) yang simpel, minimalis, dan fungsional.

## What Makes This Cool
- **Fokus & terukur**: dedicated platform untuk satu sub-jenis soal TPA
- **Progress visible**: lihat skor, waktu, dan perkembangan belajar
- **Portable**: web app bisa dibuka di HP/laptop tanpa install

## Premises
1. Web app sederhana, functional — tanpa auth/user system kompleks
2. Dimulai dari sinonim dulu, database dari PDF yang akan diekstrak
3. Fitur inti: flashcard, mode kuis (pilihan ganda), timer
4. Single-user / local-first
5. Data disimpan di file JSON lokal (belum perlu backend/database)

## Approaches Considered

### APPROACH A: Single HTML File (Vanilla)
Effort: Kecil | Risk: Rendah
- Pros: Zero setup
- Cons: Spaghetti code, susah maintain

### APPROACH B: Vite + React + Tailwind (SPA) ← RECOMMENDED
Effort: Sedang | Risk: Rendah
- Pros: Component-based, rapi, gampang dikembangin
- Cons: Perlu npm install

### APPROACH C: Next.js + SQLite (Full Stack)
Effort: Besar | Risk: Sedang
- Pros: Database beneran
- Cons: Overkill untuk single-user

## Recommended Approach
**Approach B** — Vite + React + Tailwind CSS sebagai SPA. Data dari file JSON. Cukup `npm run dev` untuk jalan.
